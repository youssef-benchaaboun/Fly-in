Parser architecture
===================

1. `read_file` owns only file access and converts operating-system failures into a
   returned error.
2. `valid_lines` removes comments and blank lines, remembers original line numbers,
   checks the mandatory first line, and rejects unknown prefixes.
3. `verifier_values` dispatches definitions to either `_parse_zone` or
   `_parse_connection`. Helpers parse common metadata and capacity rules.
4. Zones are inserted into a name dictionary immediately after successful parsing.
   This makes uniqueness checks direct and ensures a connection can reference only
   zones defined earlier in the file.
5. Undirected connections are stored as frozensets while parsing, so `a-b` and
   `b-a` compare as the same edge.
6. A `StaticMap` is created only if no errors exist and exactly one start and one end
   were parsed. No pathfinding or simulation behavior is included in this scope.
